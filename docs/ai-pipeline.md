\# AI Pipeline



\## Capture Flow



Audio

→ transcription

→ structured extraction

→ review

→ persistence



\---



\## AI Responsibilities



The AI should:

\- structure

\- extract

\- clarify

\- organize



The AI should NOT:

\- hallucinate

\- over-interpret

\- autonomously control user life



\---



\## Extraction Categories



\- tasks

\- events

\- ideas

\- notes



\---



\## Principles



\### Trust Over Automation

Conservative extraction is preferable.



\### Structured Outputs

All AI extraction should return strict JSON.



\### Human Confirmation

User review is required before persistence.
